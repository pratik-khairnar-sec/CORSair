# Security Policy

## Scope & Authorized Usage

**CORSair** is an analysis tool designed specifically for authorized security assessments, penetration testing, bug bounty programs, and educational research.

You must only use CORSair against web applications that you own or for which you have explicit written permission to test. Unauthorized cross-origin probing or data extraction may violate computer crime laws (such as the CFAA in the United States and the Computer Misuse Act in the UK).

## Reporting Vulnerabilities in CORSair

If you identify a security issue within CORSair itself (e.g., unintended XSS in report rendering or unescaped data reflection), please report it responsibly:

* **Email**: `pratik.khairnar.sec@gmail.com`
* Please do not post security vulnerabilities in public GitHub issues.
* Include reproduction steps, sample inputs, and recommended fixes if available.
